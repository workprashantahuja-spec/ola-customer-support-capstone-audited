# VIP customer handling

Treat a customer as VIP only when a human verifies an explicit account designation; never infer VIP status from a name, spending claim, or message tone.
Within the same severity level, place a verified VIP case ahead of standard cases and assign a named human case owner.
All P1 cases take priority over P2 and P3 cases, so VIP status never moves a lower-severity case ahead of a more urgent one.
The same SLA targets, refund-evidence requirements, and INR 200 service-credit limit apply to VIP and standard customers.
The case owner may personalize communication, but VIP status never permits access to another customer's records or an unapproved financial action.
