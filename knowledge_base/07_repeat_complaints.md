# Repeat-complaint handling

Treat a report as a repeat complaint when the same customer reports the same ride issue or underlying unresolved problem again within 30 calendar days.
A human links the repeat report to the existing case, preserving earlier evidence and responses instead of treating it as an unrelated issue.
When new evidence shows that a Resolved or Closed issue remains unresolved, a human reopens the case as In Progress unless its severity requires immediate P1 handling.
The third report of the same unresolved complaint within 30 calendar days requires Support Lead review, while an existing P1 case remains with its specialist lead.
A repeat report does not automatically approve a refund, service credit, or higher severity, and the agent must not claim a repeat count when complaint history is unavailable.
